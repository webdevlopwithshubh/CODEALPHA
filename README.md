## 🧠 Projects

### 🎮 Hangman Game

A simple command-line based **Hangman Game** built using Python. The player guesses letters to reveal the hidden word before running out of attempts.

#### ✨ Features

* 🎯 Random word selection
* 🔤 Letter-by-letter guessing system
* ❌ Limited attempts (6 chances)
* ⚠ Input validation (only single letters allowed)
* 🎉 Win/Lose messages

#### 🛠 Tech Used

* Python
* Random module

#### ▶️ How to Run

```bash
python CODEALPHA_HANGMAN.py
```
